くまさん家計簿 ホーム画面用入口ページ

ファイル
- index.html
- icon-180.png
- icon-192.png
- icon-512.png
- manifest.webmanifest

動作
1. この入口ページをiPhoneのSafariで開く
2. 「ホーム画面に追加」
3. ホーム画面ではくまさんアイコンが表示
4. アイコンを押すと自動的に下記Webアプリへ移動
   https://script.google.com/macros/s/AKfycbxqA6qYl-dWPsmeNe3NyWJaHvVkLOrIZEl38TJNL0RaqFi0U78_QxIF7YkSFtANmR0a/exec

GitHub Pagesへ公開する場合は、このフォルダ内の5ファイルを
同じリポジトリのルートへアップロードしてください。
